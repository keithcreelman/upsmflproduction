# Stats → Pts Agst: which window predicts the next game? (walk-forward backtest, locked)

Selection on 2019–2024 only (selection.json sha256 `af5a2637709829b4…`), then the locked 2025 holdout. Product rule: a window replaces Full season only if it beats it by ≥ 2 points of rank accuracy in BOTH periods with both 95% intervals above 0.

**Rank accuracy** = share of team pairs (same week, same position) that the window put in the same order as the next game's actual Allowed ÷ Usual. A coin flip = 50%. **MAE / RMSE** = error of the next game's points against those players (adjusted family: players' usual × the window's Allowed ÷ Usual; no leakage). **Shrunk MAE** = the same with the ratio pulled toward the league ratio by k games (k chosen leaving out the scored season). **Q-lift** = next-game Allowed ÷ Usual of the top quarter of teams by the window minus the bottom quarter. **Dir.** = share right about above/below the players' usual.
